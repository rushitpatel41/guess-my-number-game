# Guess My Number!

This is a simple "Guess My Number!" game built with HTML, CSS, and JavaScript.

## How to Play

1.  A secret number between 1 and 20 is generated.
2.  Enter your guess in the input field.
3.  Click the "Check!" button.
4.  The game will tell you if your guess is too high, too low, or correct.
5.  Your score starts at 20 and decreases with each wrong guess.
6.  The high score is saved.
7.  Click the "Again!" button to play a new game.

## Files

*   `index.html`: The main HTML file.
*   `style.css`: The CSS file for styling.
*   `script.js`: The JavaScript file with the game logic.
